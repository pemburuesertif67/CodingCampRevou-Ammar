# Life Dashboard Requirements

## Project Goal
Build a simple To-Do List Life Dashboard using HTML, CSS, and Vanilla JavaScript.

## Required Features
- Current time and date
- Time-based greeting
- 25-minute focus timer with Start, Stop, and Reset
- To-Do List with add, edit, mark done, and delete
- To-Do data persisted with browser Local Storage
- Quick Links that open favorite websites
- Quick Links persisted with Local Storage

## Selected Challenges
- Light / Dark mode
- Custom name in greeting
- Prevent duplicate tasks

## Technical Constraints
- HTML for structure
- CSS for styling
- Vanilla JavaScript; no frameworks
- No backend server
- Browser Local Storage API
- Modern browser compatibility
- One CSS file in css/
- One JavaScript file in js/
